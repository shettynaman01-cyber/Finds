# Finds — AI-Powered Food Discovery Platform

**Discover food. Explore possibilities. Find your perfect meal.**

Finds is a food discovery and delivery web application designed to make finding the right meal easier through an intuitive user experience, restaurant exploration, and AI-powered food recommendations.

The platform aims to bring food discovery, personalised recommendations, convenient ordering, and health-conscious meal exploration together in one place.

## Overview

Finds is being developed to help users explore different cuisines, discover restaurants, browse food categories, and find meals that match their preferences. The platform also introduces **Finds Wellness**, a dedicated space for healthy food choices and personalised diet-oriented recommendations.

## Key Features

- **Food Discovery** — Browse food across multiple categories, including breakfast, lunch, dinner, snacks, desserts, sweets, and beverages.
- **Restaurant Exploration** — Discover restaurants, cafés, and cuisines through a dedicated exploration experience.
- **Smart Cart Management** — Add food items to the cart and manage selected items before ordering.
- **Finds Wallet** — Apply eligible wallet vouchers to reduce the total bill.
- **AI-Powered Recommendations** — Help users discover food based on their preferences and requirements.
- **Finds Wellness** — Explore health-conscious food options and personalised meal recommendations.
- **Responsive User Interface** — A clean, accessible, and user-friendly interface designed for a smooth browsing experience.

## Technology Stack

| Technology | Purpose |
|---|---|
| React.js | Frontend user interface |
| JavaScript | Application functionality |
| Vite | Frontend development environment |
| CSS | Styling and responsive layouts |
| Node.js | Backend runtime |
| Express.js | Backend API development |
| MySQL | Relational database |
| REST APIs | Communication between frontend and backend |

## Project Structure

The application is planned around a modular architecture, separating the frontend interface from backend services and database operations.

- `frontend/` — React application, pages, components, and styles.
- `backend/` — Server-side logic, API routes, and database integration.

## Project Status

**Currently in development.**

Finds is being built incrementally, with the frontend experience established first and additional functionality introduced as development progresses.

## Vision

The goal of Finds is to create a smarter and more personalised food platform that combines food discovery, restaurant exploration, convenient ordering, and wellness-focused recommendations in a single application.
